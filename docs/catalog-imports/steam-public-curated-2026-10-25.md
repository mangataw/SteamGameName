# Steam 公开热门候选词库更新（2026-10-25）

本轮将默认内置词库从 692 条扩充到 714 条，共新增 22 条。目标不是覆盖榜单里的所有名称，而是补齐公开使用场景中更常见、且中文译名已经稳定的游戏。

## 候选来源

- Steam 当前“最多游玩”Top 100。
- Steam 当前“全球畅销”Top 100。
- Steam “年度最佳”2021、2022、2023、2024、2025 页面中的游戏候选。
- 以上来源合并后共有 800 个唯一 AppID；入库快照及逐条来源记录见 `steam-public-curated-2026-10-25.json`。

榜单只用于发现候选，不直接决定是否入库。每个最终条目必须至少命中一个来源，并再次通过 Steam 商店详情接口核对当前简体中文名称与内容类型。

## 筛选规则

1. 只收录 `game` 类型，排除 DLC、Demo、软件、工具、服务器与测试条目。
2. Steam 当前简体中文商店名称已经包含汉字时不重复收录，继续尊重 Steam 自带名称。
3. 排除仅有品牌或专有写法、中文化收益有限的名称，例如 `DayZ`、`VRChat`。
4. 排除中文通称存在明显竞争或尚未稳定的名称，例如 `Among Us`。
5. 只采用长期通行、歧义较低的简体中文译名；不为扩大数量而猜译新作。
6. AppID 必须未被现有词库收录，新增后仍按 AppID 数值升序保存。

## 本轮结果

- 新增 22 条：其中 13 条命中当前榜单，19 条命中一个或多个 2021–2025 年度榜单，10 条同时命中两类来源。
- 保留了跨年度热门作品，如《收获日 2》《流放之路》《未转变者》《木筏求生》《严阵以待》。
- 补充了当前热门作品，如《杀戮尖塔 2》《怪物猎人：荒野》《鸣潮》《逃离塔科夫》。
- 未收录 Steam 简中名称已经含汉字的候选；也未收录品牌名、非游戏内容和低置信译名。

## 验证要求

- `pnpm run validate:catalog`：检查 Schema、AppID 排序、重复项、译名汉字与危险字符。
- `pnpm run check`：执行类型检查、仓库约束、Lua 检查、前后端测试和词库验证。
- `pnpm run build` 与 `pnpm run verify:star`：确认扩充后的完整内置词库能够打包并通过产物校验。

这份记录与 JSON 快照共同作为本次数据提交的审计依据；以后榜单变化时新增下一期快照，不回写本期记录。
