# Steam 热门 Top 100 词库缺口评估（2026-10-25）

数据基线：Steam 官方 [Most Played](https://store.steampowered.com/charts/mostplayed) 榜单与 `ISteamChartsService/GetMostPlayedGames/v1/` 返回的当前 100 个 AppID。简体中文商店名用于判断 Steam 客户端是否已经包含汉字；现有词库基线为 692 条。

## 结论

- 现有词库直接覆盖 28 个 Top 100 AppID。
- 约 38 个未收录项目在 Steam 简体中文名称中已经包含汉字，按项目规则无需重复映射。
- 约 32 个项目仍以纯外文显示，值得逐项评估。
- 另有 2 个榜单 AppID 在评估时无法从公开商店详情接口取得有效名称，不应猜测或收录。

当前 692 条主要来自维护者个人游戏库，无法代表公开用户的热门游戏分布。社区提交前应增加一轮独立的热门词库数据提交，但不需要为了覆盖率强行翻译品牌、平台、软件、Demo 或中文译名尚未稳定的新作。

## 暂缓或排除

- `FiveM`、`VRChat`、`BeamNG.drive`、`eFootball`、`DayZ`、`R.E.P.O.` 等主要作为品牌或专有写法使用，中文化收益较低，默认暂缓。
- `OBS Studio` 是软件，不属于当前“游戏名称中文化”的首版范围。
- `Deadlock`、`WARDOGS`、`ARC Raiders`、`FINAL FANTASY RESONANCE` 等新作或名称策略仍可能变化，等待译名稳定后再评估。
- Steam 简体中文名称已经包含汉字的项目保持 Steam 原名，不进入词库，即使其名称仍混有英文品牌。

## 建议执行顺序

1. 将第一批高置信候选整理为独立 JSON 导入文件，并逐条核对来源。
2. 运行 Schema、排序、重复 AppID、默认名称含汉字排除和完整测试门禁。
3. 使用单独的 `data:` 提交合入 `main`，让远程词库先取得数据更新。
4. 构建包含更新后完整词库的候选包，抽样验证显示和中文搜索。
5. 冻结正式 GitHub Release 所引用的源码提交；项目后来决定不提交 PluginDatabase。
