# 项目状态与验收清单

评估基线：`PLANS.md` 的首版成功标准、自动化测试计划、手工验收计划和完成定义。

## 当前结论

当前版本适合作为 `v0.1.0` 预览版提交和发布：源码可类型检查、测试、校验、正式构建并打包，但尚不满足计划对稳定首版的完整完成定义。仓库中的自动化结果不能代替 Steam 与 Millennium 真机验证。

## 已有证据

- [x] AppID 精确匹配、三种显示模式、已有汉字名称保持不变。
- [x] 内置词库、缓存读取、ETag/Last-Modified 请求、失败回退和设置持久化已有实现。
- [x] 左栏限制性补丁、响应式前端存储、设置页面和手动刷新已有实现。
- [x] CI、标签 Release、ZIP 和 SHA-256 打包工作流已有实现。
- [x] TypeScript 类型检查通过。
- [x] 23 项 Vitest 测试通过，7 条内置翻译通过校验。
- [x] Starlight 正式构建和发布打包通过。
- [x] 安装、卸载、隐私、故障排查和贡献文档已有基础说明。

## 稳定版前的阻断项

- [ ] 为 Lua 后端增加可重复的语法/静态检查，并纳入 CI。
- [ ] 覆盖无缓存、损坏缓存、远程 200/304、DNS/TLS/超时、非法远程数据、原子写入失败、非法设置和并发刷新等后端测试。
- [ ] 让补丁测试直接验证生产补丁的查找与替换，并覆盖重复加载、卸载清理和更多真实 Steam fixture。
- [ ] 在 Windows 10 与 Windows 11、Steam 稳定版、目标 Millennium 版本上完成小型库和大型库测试。
- [ ] 在 Steam 简体中文与英文界面验证在线、离线、GitHub 不可达和超时场景。
- [ ] 验证仅左栏发生变化，搜索、详情页、下载页、右键菜单和启动游戏不受影响。
- [ ] 验证禁用、卸载和补丁失配后完整恢复或安全降级。
- [ ] 从 GitHub Release 在干净 Millennium 环境安装 ZIP，并验证远程词库更新无需重启即可生效。

## 建议发布路径

1. 将当前版本推送至 GitHub，作为源码和词库的权威仓库。
2. 开启 `main` 分支保护、Actions 必需检查和 PR 审核。
3. 修复上述自动化缺口，发布 `v0.1.x` 预览标签并执行真机矩阵。
4. 记录测试过的 Steam/Millennium 版本及已知限制，满足门禁后发布稳定版本。
5. 向 `SteamClientHomebrew/PluginDatabase` 提交 PR，将本仓库作为子模块固定到已验证提交；后续插件更新通过新的指针 PR 发布，纯词库更新可继续由 `main` 的 Raw 文件提供。
