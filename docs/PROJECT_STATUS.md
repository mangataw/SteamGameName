## 真机验证记录

### 2026-08-24：`v0.1.0` 发布包未出现在插件列表

- 环境：Windows，Steam 桌面客户端，Millennium `v3.4.1`。
- 现象：将发布 ZIP 解压到本机实际插件目录后，Millennium 插件列表仍为空。
- 定位：ZIP 内只有无扩展名的 `steam-game-name-zh`；该文件本身可通过 Starlight v2 四区段校验，但 Millennium 只识别 `.star` 插件包。
- 临时规避：将文件重命名为 `steam-game-name-zh.star` 后重新启动 Steam。
- 下版本验收：正式构建直接生成 `.star` 文件；ZIP 保留该扩展名；自动化检查归档条目名并运行 `starlight verify`；在干净的 Millennium `v3.4.1` 环境解压、重启后，插件列表能够显示“Steam 游戏名中文化”。

## 建议发布路径

1. 将当前版本推送至 GitHub，作为源码和词库的权威仓库。
2. 开启 `main` 分支保护、Actions 必需检查和 PR 审核。
3. 修复上述自动化缺口，发布 `v0.1.x` 预览标签并执行真机矩阵。
4. 记录测试过的 Steam/Millennium 版本及已知限制，满足门禁后发布稳定版本。
5. 向 `SteamClientHomebrew/PluginDatabase` 提交 PR，将本仓库作为子模块固定到已验证提交；后续插件更新通过新的指针 PR 发布，纯词库更新可继续由 `main` 的 Raw 文件提供。
