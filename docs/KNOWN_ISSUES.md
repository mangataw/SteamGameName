# 已知问题

## Millennium 启动期插件操作菜单偏移或消失

状态：已确认为 Millennium 宿主界面问题，非本插件设置组件缺陷；当前没有直接功能影响，延后单独向上游报告，不阻断 `v1.0.0-rc.1` 主线。

### 现象

- Steam/Millennium 刚启动时，在 Millennium 的“插件”页面展开插件操作菜单并点击“配置”，菜单可能移动到 Steam 窗口左上角。
- 严重时菜单会在左上角一闪而过后消失，配置页面没有打开。
- 启动后等待一段时间，出现概率明显降低。
- 插件卡片中的包大小和 CPU 占用徽章约每 3 秒闪动一次；问题容易在该刷新时发生。

### 归因证据

- 偏移的是 Millennium 提供的整块插件操作菜单，而不是本插件配置页中的控件。
- 本插件前端没有 3 秒定时刷新；词库自动检查只在启动初始化后执行一次。
- 安装 Extendium 后可在其操作菜单中复现相同行为，证明问题不依赖本插件的词库、状态存储或设置组件。
- 当前最符合证据的原因是 Millennium 更新插件资源统计时重新渲染插件卡片，使已打开菜单的定位锚点失效；菜单 Portal 随后回退到窗口左上角，点击“配置”的流程也可能被重挂载中断。

### 临时规避

等待 Steam 和 Millennium 启动稳定、插件卡片的资源统计不再明显闪动后再打开“配置”。不要通过连续点击配置入口规避，以免反复触发同一竞态。

### 项目处理原则

- 不在本插件中加入固定延时、自动重试点击、隐藏菜单或其他掩盖上游竞态的补丁。
- 在独立跟踪阶段向 Millennium 上游提交包含截图、Steam/Millennium 版本、约 3 秒刷新周期、跨 Extendium 复现和操作步骤的问题报告。
- 跟踪上游修复并在 Steam Stable/Beta 上复验。只有上游修复要求本插件做兼容调整，或发现可靠且不影响其他菜单的插件侧方案时，才安排 `v0.2.1`。
- 此问题不阻断词库数据维护和 `v1.0.0-rc.1` 的其他公共发布准备；RC 验收报告必须如实披露该上游已知问题。
